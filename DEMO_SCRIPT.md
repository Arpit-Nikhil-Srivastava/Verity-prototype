# Demo script (about 3 minutes)

Record your screen while you use the app. The brief asks for a walkthrough where you actually use the prototype, not slides. Start from a fresh state: stop the server, delete `db.json`, run `node server.js`, open the app, press the reset button (↺).

| Time | Do | Say |
|---|---|---|
| 0:00 | Show Decisions and the trust ring | "In 2040 an agent shops for you. Verity checks every action before it happens." |
| 0:15 | Explore, Packs, send **Scam wave** | "Here are two actions with a fake discount, a pressure tactic and surge pricing." |
| 0:30 | Open one held decision | "Verity held it. The receipt shows the risk split and who benefits from the pick." |
| 0:55 | Back to the feed, open a clean one | "Honest picks pass without interrupting me." |
| 1:05 | Your Call, choose first, then reveal | "I decide first, then see what the agent would have chosen. That is how I keep my own preferences." |
| 1:25 | Explore, Controls: autopilot, trusted-only | "Rules are mine, and the gateway enforces them for every agent." |
| 1:45 | Explore, Connect, **Run a sample check**, then open the checkout demo page | "A marketplace calls one endpoint before an order. It gets allow, hold or block, and a signed receipt." |
| 2:10 | Explore, Receipts, **Verify audit chain** | "Receipts are chained, so editing history is detectable." |
| 2:20 | Explore, Import, **Load messy sample**, Analyze, Backtest | "I can import past orders, even messy ones, and see how my rules would have behaved." |
| 2:45 | Press ↺ reset | "One tap starts again from scratch." |
| 2:55 | Close | "Success is the agreement rate: how often the agent's pick matches mine." |

Tips: keep the window phone-width; do not read every number; if something fails on camera, reset and retake.
